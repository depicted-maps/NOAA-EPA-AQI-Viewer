What's included
- Project overview: NOAA hourly PM₂.₅ forecast animation for the United States and Canada.
- NOAA documentation: Links to the NOAA OSTI Air Quality Modeling page and official forecast services.
- Animation features: Smooth playback, stationary values when paused, and NOAA's original forecast colors.
- Geographic governance: Web Mercator (EPSG:3857), state and provincial boundaries, and projection requirements.
- GitHub installation: Instructions for publishing the HTML viewer through GitHub Pages.
- Validation: What has been implemented, what NOAA's service metadata confirms, and what still needs testing.
- Attribution: Proper credit to NOAA/NWS, distinguishing the independent viewer from an official NOAA application.
NOAA's service metadata confirms that the operational product provides hourly PM₂.₅ forecast concentrations in µg/m³, normally updated twice daily.
