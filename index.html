Display projection: EPSG:3857 (NOAA operational service); model source grid is separate. The NOAA forecast is continuously updated. Click the map to pause and display NOAA model values at fixed positions.

Inspection mode: Values are hidden during playback. Pause the animation by clicking the map, using the Pause button, or moving the slider. Stationary labels are sampled from NOAA’s hourly PM₂.₅ raster for the selected time. Unavailable queries are left blank. No city names or simulated values.

Outlines: Esri Living Atlas World Administrative Divisions provides the same first-level polygon geometry source for U.S. states and Canadian provinces. Only white outlines are drawn; no land-color or water-area layer is displayed. Polygon coastlines may still appear as boundary edges. All boundary coordinates use the same Web Mercator extent as NOAA imagery. The outlines never supply PM₂.₅ values or colored masks. Boundary visibility can be toggled. If boundary retrieval fails, the forecast continues playing and reports that the overlay is unavailable.

Source: NOAA/NWS NDGD hourly PM₂.₅ ImageServer. Administrative outlines: Esri World Administrative Divisions (Esri/Garmin). The service determines available forecast times; no missing data are generated or interpolated. Frames are requested for one-hour valid-time windows using identical bounding boxes and display settings. The selected color rendering is NOAA's apm25_color service function. NOAA is the data provider, not the publisher of this demonstration.

If NOAA blocks browser requests, is temporarily unavailable, or returns no imagery, this demo reports an error rather than substituting simulated maps. Some browsers restrict remote requests when opened as a local file: if so, serve this HTML via a local web server or GitHub Pages.
